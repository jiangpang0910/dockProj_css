    Watch the solver think

    Pick a project with open conflicts and start a run. The solver works in four stages, one after another. Each stage locks in its best answer before the next one starts:

    1. Place as many conflicts as possible
    2. Least disruption: delay·w + early·w + moves·w
    3. Tightest fit: wasted berth length × days
    4. Stay on the requested berth: days moved off it

    For each stage you'll see the best answer found (the loss) and the bound: the best any answer could possibly be. Where the two meet, the answer is proven optimal. Where the best answer stops moving early, extra seconds buy nothing. The time-limit advisor turns that into a timeLimitSec.
